# Maschera di Inserimento/Modifica/Visualizzazione di un movimento contabile

Maschera di Inserimento/Modifica/Visualizzazione di un [movimento contabile](/admin_accountingentries)
e dei suoi dettagli:
- [Righe contabili](/admin_accountingentries_accountingline)
- [Dettaglio IVA](/admin_accountingentries_vatdetail)
- [Ritenute d'acconto](/admin_accountingentries_withholdingdetail)

![Mappa modifica/inserimento](./images/mappamovimenti.jpg)

**In questa maschera è possibile definire:**
## Data registrazione
La data registrazione del moviemtno contabile.

## Tipo movimento
Tipologia del movimento contabile :
- Articolo Semplice
- Articolo Complesso
- Fattura Cliente
- Fattura Fornitore
- Nota credito Cliente
- Nota credito Fornitore
- Movimenti di apertura
- Movimenti di chiusura

## Causale
La [causale](/admin_accountingreasons) del movimento contabile.

## Descrizione registrazione
Descrizione libera del movimento contabile.

## Data documento
La data del documento contabile.

## Numero documento
Numero identificativo del documento contabile.

## Registro IVA
[Registro IVA](/admin_vatregistertypes) del documento contabile.

## Importo
Importo totale del movimento.

## Modalità di pagamento
La modalità di pagamento del movimento contabile.

## Fornitore
[Fornitore](/admin_suppliers) a cui è riferito il movimento contabile.

## Cliente
[Cliente](/admin_customers) a cui è riferito il movimento contabile.

## Documenti
## Fattura PDF
Fattura in formato PDF.

## Fattura XML
Fattura in formato XML valido per la fatturazione elettronica.

## Note
Note libere del movimento contabile.
