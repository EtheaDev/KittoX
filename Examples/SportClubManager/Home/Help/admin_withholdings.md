# Ritenute d'acconto

Nel [menu amministratore](/administrator_menu), alla voce Contabilità è possibile gestire le ritenute d’acconto.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle ritenute d’acconto inserite.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Esercizio: (filtra l'elenco in base al [esercizio contabile](/admin_financialyears))

- Mese: (filtra l'elenco in base la mese della data documento del movimento contabile)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una nuova [ritenuta d'acconto](/admin_withholdings_withholdingdetail)
- ![](./images/edit_record.png) Modifica di una [ritenuta d'acconto](/admin_withholdings_withholdingdetail)
- ![](./images/delete_record.png) Cancellazione di una ritenuta d'acconto
- ![](./images/view_record.png) Visualizzazione di una [ritenuta d'acconto](/admin_withholdings_withholdingdetail)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco delle ritenute d'acconto
