# Rate iscrizioni

Nel [menu amministratore](/administrator_menu), alla voce Gestione Iscrizione è possibile visualizzare le rate degli iscritti.

### Finestra elenco con filtro di ricerca
Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Filtro sulla descrizione della rata)

- Stagione: (Filtro sullo stagione)
- Attuale
- Precedente

- Status: (Filtro sullo stato della rata)
- Inserita
- Pagata
- Parz. Pagata

- Dalla data: (Filtro sulla data scadenza della rata)

- Alla data: (Filtro sulla data scadenza della rata)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/refresh.png) Aggiornamento elenco (refresh)
