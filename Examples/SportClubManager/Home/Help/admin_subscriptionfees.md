# Quote iscrizioni

Nel [menu amministratore](/administrator_menu), alla voce Gestione Iscrizioni è possibile gestire le quote di iscrizione.

Ogni anno occorre definire la Quote di iscrizione, per permettere agli utenti (genitori) di iscrivere i propri figli ai vari corsi.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle quote inserite.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Mostra quote: (filtra l'elenco in base allo stato della quota):
- Attive
- Future
- Storico

- Annata: (Filtro in base all'annata per cui la quota è valida)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuova [Quota](/admin_subscriptionfees_subscriptionfee)
- ![](./images/edit_record.png) Modifica di una  [Quota](/admin_subscriptionfees_subscriptionfee)
- ![](./images/delete_record.png) Cancellazione di una Quota
- ![](./images/view_record.png) Visualizzazione di una  [Quota](/admin_subscriptionfees_subscriptionfee)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco Quote
