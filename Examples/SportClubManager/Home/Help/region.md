# Regioni

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri geografici è possibile gestire le regioni.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle regioni.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, regione, area geografica)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [regione](/region_region)
- ![](./images/edit_record.png) Modifica di una [regione](/region_region)
- ![](./images/delete_record.png) Cancellazione di una nazione
- ![](./images/view_record.png) Visualizzazione di una [regione](/region_region)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
