# Codici IVA

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri Contabili è possibile gestire i codici IVA.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista dei codici IVA.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione, codice detraibile, codice indetraibile, titolo, natura)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [codice IVA](/admin_vatcodes_vatcode)
- ![](./images/edit_record.png) Modifica di un [codice IVA](/admin_vatcodes_vatcode)
- ![](./images/delete_record.png) Cancellazione di un codice IVA
- ![](./images/view_record.png) Visualizzazione di un [codice IVA](/admin_vatcodes_vatcode)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) dei codici IVA
