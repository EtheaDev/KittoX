# Situazione
Nel [menu amministratore](/administrator_menu), alla voce Gestione Iscrizione è possibile visualizzare la situzione del pagamento dell'iscrizione.

### Finestra elenco con filtro di ricerca
Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Nominativo: (Filtro sul cognome e nome iscritto, e sul cognome e nome genitore)

- Stagione: (Filtro sullo stagione)
- Attuale
- Precedente

- Corsi attivi: (Filtro sui corsi attivi dell'iscrizione)

- Anno nascita dal: (Filtro sulla data nascita dell'iscritto)

- Anno nascita dal: (Filtro sulla data nascita dell'iscritto)

- Dalla data: (Filtro sulla data iscrizione)

- Alla data: (Filtro sulla data iscrizione)
