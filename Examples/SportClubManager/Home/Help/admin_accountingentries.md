# Movimenti contabili

Nel [menu amministratore](/administrator_menu), alla voce Contabilità è possibile gestire i movimenti contabili.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista movimenti contabili inseriti.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Esercizio: (filtra l'elenco in base al [esercizio contabile](/admin_financialyears))

- Nr. mov.: (filtra l'elenco in base al numero movimento contabile)

- Dalla data: (filtra l'elenco in base alla data registrazione)

- Alla data: (filtra l'elenco in base alla data registrazione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuovo [movimento contabile](/admin_accountingentries_accountingentry)
- ![](./images/edit_record.png) Modifica di un [movimento contabile](/admin_accountingentries_accountingentry)
- ![](./images/delete_record.png) Cancellazione di un movimento contabile
- ![](./images/view_record.png) Visualizzazione di un [movimento contabile](/admin_accountingentries_accountingentry)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco movimenti contabili
