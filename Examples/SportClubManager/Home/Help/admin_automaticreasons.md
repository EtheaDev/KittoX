# Causali automatiche

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri Contabili è possibile gestire le causali automatiche.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle causali automatiche.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice e descrizione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [causale automatica](/admin_automaticreasons_automaticreason)
- ![](./images/edit_record.png) Modifica di una [causale automatica](/admin_automaticreasons_automaticreason)
- ![](./images/delete_record.png) Cancellazione di una causale automatica
- ![](./images/view_record.png) Visualizzazione di una [causale automatica](/admin_automaticreasons_automaticreason)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
