# Partite

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire le partite.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle partite.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su descrizione giornata, squadra, squadra avversaria, luogo di ritrovo, campionato, impianto sportivo, stagione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [partita](/match_match)
- ![](./images/edit_record.png) Modifica di una [partita](/match_match)
- ![](./images/delete_record.png) Cancellazione di un partita
- ![](./images/view_record.png) Visualizzazione di un[partita](/match_match)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
