# Maschera di Inserimento/Modifica/Visualizzazione di un esercizio contabile

Maschera di Inserimento/Modifica/Visualizzazione di un [esercizio contabile](/admin_financialyears).

![Mappa modifica/Visualizzazione](./images/esercizicontabilimappa.jpg)

**In questa maschera è possibile definire:**
## Anno
Anno del esercizio contabile.

## Esercizio
Descrizione dell'esercizio contabile.

## Data inizio
Data inizio esercizio contabile.

## Data fine
Data fine esercizio contabile.

## Stato
Stato dell'esercizio contabile:
- Aperto
- Chiuso

## Ultimo numero movimento utilizzato
L'ultimo numero movimento utilizzato nei movimenti contabili per l'esercizio.
