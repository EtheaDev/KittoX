# Maschera di Inserimento/Modifica/Visualizzazione utente
Maschera di inserimento/modifica/visualizzazione degli [utenti](/admin_users) di [Sport Club Manager](/start).
Sono presenti due dettagli:
- [Utente](/admin_users_user#utente)
- [configurazione](/admin_users_user#configurazione)

## Utente
![Mappa modifica/inserimento](./images/mappautente.jpg)

In questa maschera è possibile definire:
## Id account
Id delle utente nel caso di utenti non amministratori corrisponde al codice fiscale.

## Codice fiscale
Codice fiscale dell'utente.

## Descrizione
Descrizione dell'utente.

## Cognome
Cognome dell'utente.

## Nome
Nome dell'utente.

## E-mail
Inidirizzo di posta elettronica dell'utente.

## N.cellulare
Numero cellulare dell'utente.

## Profilo
Profilo dell'utente.

## Amministratore
Indica se l'utente è un amministratore.

## Configurazione
![Mappa modifica/inserimento](./images/mappautente1.jpg)


In questa maschera è possibile definire:
## Di sistema
Utente amministratore di sistema.

## Accesso bloccato
Utente bloccato.

## Password aggiornare
Password provvisoria da aggiornare dall'utente.

## Consenso Privacy
L'utente ha accettato il consenso della privacy per il sistema.

## Data ora creazione
Data di creazione dell'utente.
