# Causali contabili

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri Contabili è possibile gestire le causali contabili.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle causali contabili.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice causale e descrizione)

- Tipo registrazione: (Ricerca su tipo registrazione)
- Articolo semplice
- Articolo complesso
- Fattura fornitore
- Fattura cliente
- Nota credito fornitore
- Nota credito cliente
- Movimenti di apertura
- Movimenti di chiusura

- Tipo causale: (Ricerca su tipo causale)
- Contabilità generale
- Iva vendite
- Iva acquisti
- Incasso
- Pagamento

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [causale contabile](/admin_accountingreasons_accountingreason)
- ![](./images/edit_record.png) Modifica di una [causale contabile](/admin_accountingreasons_accountingreason)
- ![](./images/delete_record.png) Cancellazione di una causale contabile
- ![](./images/view_record.png) Visualizzazione di una [causale contabile](/admin_accountingreasons_accountingreason)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) delle causali contabili
