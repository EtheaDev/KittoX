# Riepilogo pagamenti

Nel [menu utente](/user_application), alla voce Riepilogo pagamenti è possibile visualizzare il riepilogo dei pagamenti del proprio nucleo familiare.

### Finestra elenco del riepilogo rate con filtro di ricerca

Elenco del riepilogo delle rate del proprio nucleo familiare.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Status: (Filtro sullo status del pagamento)
- Approvato
- Inserito
- Rifiutato

- Dalla data: (Filtro sulla data del pagamento)

- Alla data:  (Filtro sulla data del pagamento)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/edit_record.png) Modifica di un [pagamento](/user_paymentsummary_payment) (non ancora approvato o rifiutato)
- ![](./images/delete_record.png) Cancellazione di un [pagamento](/user_paymentsummary_payment) (non ancora approvato o rifiutato)
- ![](./images/view_record.png) Visualizzazione dei dati del [pagamento](/user_paymentsummary_payment)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
