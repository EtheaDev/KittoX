# Tipi visite mediche

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire le tipologie di visite mediche.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista dei tipi visite mediche.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione, scadenza)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [tipo visita medica](/medicalvisittype_medicalvisittype)
- ![](./images/edit_record.png) Modifica di un [tipo visita medica](/medicalvisittype_medicalvisittype)
- ![](./images/delete_record.png) Cancellazione di un tipo visita medica
- ![](./images/view_record.png) Visualizzazione di un [tipo visita medica](/medicalvisittype_medicalvisittype)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
