# Gestione Documenti

Nel [menu utente](/user_application), alla voce Documenti è possibile visualizzare la gestione dei documenti del proprio nucleo familiare.

### Finestra elenco documenti del nucleo familiare


Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuovo [documento](/user_documents_document)
- ![](./images/edit_record.png) Modifica di un [documento](/user_documents_document)
- ![](./images/delete_record.png) Cancellazione di un [documento](/user_documents_document)
- ![](./images/view_record.png) Visualizzazione dei [documenti](/user_documents_document)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
