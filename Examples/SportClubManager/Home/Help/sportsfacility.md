# Impianti sportivi

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire gli impianti sportivi.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista degli impianti sportivi.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su impianto, indirizzo, comune, provincia, cap, fondo campo, tipo impianto)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [impianto sportivo](/sportsfacility_sportsfacility)
- ![](./images/edit_record.png) Modifica di un [impianto sportivo](/sportsfacility_sportsfacility)
- ![](./images/delete_record.png) Cancellazione di un impianto sportivo
- ![](./images/view_record.png) Visualizzazione di un [impianto sportivo](/sportsfacility_sportsfacility)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
