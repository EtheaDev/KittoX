# Riepilogo rate

Nel [menu utente](/user_application), alla voce Pagamenti è possibile visualizzare il riepilogo delle rate del proprio nucleo familiare.

### Finestra elenco del riepilogo rate con filtro di ricerca

Elenco del riepilogo delle rate del proprio nucleo familiare.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Stagioni: (Filtro sulla stagione in base allo stato)
- Corrente
- Passate

Sulla toolbar è possibile effettuare le operazioni di:
- ![](./images/view_record.png) Visualizzazione dei dati della [rata d'iscrizione](/user_subscriptioninstalments_subscriptioninstalment)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
