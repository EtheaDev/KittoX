# Elenco delle partite del campionato
Lista delle partite del [campionato](/championship).

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una partita
- ![](./images/edit_record.png) Modifica di una partita
- ![](./images/delete_record.png) Cancellazione di una partita
- ![](./images/refresh.png) Aggiornamento elenco (refresh)

![Mappa elenco](./images/campionatimappapartite.jpg)

## Maschera di Inserimento/Modifica/Visualizzazione delle partite del campionato

![Mappa documenti](./images/campioantimappapartitemappa.jpg)

**In questa maschera è possibile definire:**
## Numero gara
Numero gara della partita.

## Descrizione giornata
Descrizione della giornata di campionato.

## Data partita
Data della partita.

## Ora partita
Orario della partita.

## Casalinga
Indica se la partita è in casa.

## Squadra
[Squadra](/admin_teams) di casa.

## Punti
Punti squadra di casa.

## Set
Per i tipi di sport con set numero set vinti dalla squadra di casa.

## Avversario
[Squadra](/admin_teams) avversaria.

## Punti avversario
Punti squadra avversaria.

## Set avversario
Per i tipi di sport con set numero set vinti dalla squadra avversaria.

## Data ritrovo
Data del ritrovo pre-partita.

## Luogo ritrovo
Luogo del ritrovo pre-partita.

## Note
Note libere sulla partita.

## Impianto sportivo
L'[impianto sportivo](/sportsfacility) della partita.

## Stagione
La [stagione](/admin_seasons_season) della partita.
