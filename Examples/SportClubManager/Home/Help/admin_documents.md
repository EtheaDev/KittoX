# Documenti

Nel [menu amministratore](/administrator_menu), alla voce Gestione Anagrafiche è possibile visualizzare i Documenti dei nominativi.

### Finestra elenco con filtro di ricerca

Dall'elenco nella voce Documenti è possibile vedere la lista dei documenti raggruppati per nominativo.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Tipo Documento: (filtra l'elenco sul tipo di documento)
- Autocertificazione
- Cartellino
- Carta di Identità
- Ricevuta detrazione fiscale
- Patente
- Passaporto
- Tessera sanitaria
- Visita medica
- Altro

- Ricerca libera: (filtra sulla descrizione, ente rilasciante, numero e note del documento)

- Scaduti: (filtra sulla data di scadenza)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuova [Documento](/admin_documents_document)
- ![](./images/edit_record.png) Modifica di una [Documento](/admin_documents_document)
- ![](./images/delete_record.png) Cancellazione di un Documento
- ![](./images/view_record.png) Visualizzazione di una [Documento](/admin_documents_document)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco dei documenti
