# Elenco della rosa di una squadra
Lista della rosa di una [squadra](/admin_teams_team).

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un nuovo documento per il nominativo
- ![](./images/edit_record.png) Modifica di un documento per il nominativo
- ![](./images/delete_record.png) Cancellazione di un documento per il nominativo
- ![](./images/view_record.png) Visualizzazione di un documento per il nominativo
- ![](./images/refresh.png) Aggiornamento elenco (refresh)

![Mappa modifica/inserimento](./images/mappasquadrarosa.jpg)

## Maschera di Inserimento/Modifica/Visualizzazione degli addetti di una squadra

![Mappa documenti](./images/mappasquadrarosamappa.jpg)

**In questa maschera è possibile definire:**
## Nominativo
[Nominativo](/admin_people) dell'atleta.

## Numero maglia
Numero della maglia dell'atleta.

## Ruolo
La [ruolo](/playerrole) nella squadra dell'atleta.
