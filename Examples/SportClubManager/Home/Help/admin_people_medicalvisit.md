# Elenco delle visite mediche di un nominativo
Lista delle visite mediche di un nominativo.

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento una nuova visita medica per il nominativo
- ![](./images/edit_record.png) Modifica di una visita medica per il nominativo
- ![](./images/delete_record.png) Cancellazione di una visita medica per il nominativo
- ![](./images/view_record.png) Visualizzazione di una visita medica per il nominativo
- ![](./images/refresh.png) Aggiornamento elenco (refresh)

![Elenco ruoli/mansioni](./images/mappanominativivisite.jpg)

## Maschera di Inserimento/Modifica/Visualizzazione dei ruoli/mansioni di un nominativo


![Mappa visite mediche](./images/mappavisitemediche.jpg)

**In questa maschera è possibile definire:**
## Tipo visita medica
Tipologia della [visita medica](/medicalvisittype).

## Cod. tessera sanitaria
Codice della tessera sanitaria del nominativo.

## Data visita
Data della visita medica.

## Ora
Ora della visita medica.

## Scadenza
Fine validità del ceritificato della visita medica.

## Ambulatorio
[Ambulatorio](/admin_clinics) dove è stata effettuata la visita.
