# Elenco Rate dell'iscrizione

Lista delle rate di un [iscrizione](/user_subscriptions).

Sulla toolbar è possibile effettuare le operazioni di:
- ![](./images/view_record.png) Visualizzazione di una rata
- ![](./images/refresh.png) Aggiornamento elenco (refresh)

![Mappa modifica/inserimento](./images/user_riepiscrizionimapparate.jpg)

## Maschera di Visualizzazione delle rate dell'iscrizione

![](./images/user_riepiscrizionimapparatemappa.jpg)


**In questa maschera è possibile visualizzare:**
## Iscrizione
Descrizione dell'iscrizione.

## Data scadenza
Data scadenza della rata.

## Importo
L'importo della rata.

## Sconto/Abbuono
L'importo dello sconto sulla rata.

## Importo totale
Importo meno l'importo dello sconto/abbuono.

## Importo pagato
L'importo della rata già pagato.

## Importo residuo
Importo totale meno l'importo pagato.

## Status
Lo stato della rata:
- Inserita
- Parz. pagata
- Pagata
