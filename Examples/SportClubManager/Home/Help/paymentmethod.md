# Modalità di pagamento

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri amministrativi è possibile gestire le modalità di pagamento.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle modalità di pagamento.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, modalità di pagamento)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [modalità di pagamento](/paymentmethod_paymentmethod)
- ![](./images/edit_record.png) Modifica di una [modalità di pagamento](/paymentmethod_paymentmethod)
- ![](./images/delete_record.png) Cancellazione di una modalità di pagamento
- ![](./images/view_record.png) Visualizzazione di una [modalità di pagamento](/paymentmethod_paymentmethod)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
