# Elenco dei ruoli/mansioni di un nominativo
Lista dei ruoli/mansioni di un nominativo all'interno della società sportiva.

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuovo nominativo
- ![](./images/edit_record.png) Modifica di un nominativo
- ![](./images/delete_record.png) Cancellazione di un nominativo
- ![](./images/view_record.png) Visualizzazione di un nominativo
- ![](./images/refresh.png) Aggiornamento elenco (refresh)

![Elenco ruoli/mansioni](./images/mappanominativoruoli.jpg)
