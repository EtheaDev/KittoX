# Famiglie

Nel [menu amministratore](/administrator_menu), alla voce Gestione Anagrafiche è possibile gestire le Famiglie.

Le famiglie vengono generate in automatico al momento dell'iscrizione partendo dall'iscritto e dai dati del genitore inserito se l'iscrizione avviene dall'amministratore, o dal genitore/utente che iscrive il proprio figlio tramite [Sport Club Manager](/start) dalla versione utente/socio.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle famiglie tramite il Codice fiscale, Cognome e Nome del Creatore della famiglia.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Nominativo: (filtra l'elenco sul nome e cognome genitore della famiglia)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuova [famiglia](/admin_families_familymember)
- ![](./images/edit_record.png) Modifica di una [famiglia](/admin_families_familymember)
- ![](./images/delete_record.png) Cancellazione di una famiglia
- ![](./images/view_record.png) Visualizzazione di una [famiglia](/admin_families_familymember)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco delle famiglie
