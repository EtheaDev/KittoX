# Conti contabili

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri Contabili è possibile gestire i conti contabili.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista dei conti contabili.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su descrizione, codice padre e codice conto)

- Sezione: (Ricerca sulla sezione)
- Attivo
- Passivo
- Costi
- Ricavi

- Livello: (Ricerca sul livello)
- Mastro
- Conto
- Sottoconto

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [conto contabile](/admin_ledgeraccounts_ledgeraccount)
- ![](./images/edit_record.png) Modifica di un [conto contabile](/admin_ledgeraccounts_ledgeraccount)
- ![](./images/delete_record.png) Cancellazione di un conto contabile
- ![](./images/view_record.png) Visualizzazione di un [conto contabile](/admin_ledgeraccounts_ledgeraccount)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) dei conti contabili
