# Modifica password

Dal [menu amministratore](/administrator_menu) o [menu utente](/user_application) è possibile accedere alla maschera di modifica della password  dell' utente collegato.

![Mappa dai profilo](./images/modificapassword.jpg)

In questa maschera è possibile definire:
#### Vecchia password
La password da modificare.

#### Nuova password
La nuova password dell'utente.

#### Conferma nuova password
Conferma della nuova password dell'utente.
