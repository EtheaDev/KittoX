# Tipi documenti

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire i tipi documenti.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista dei tipi documento.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [tipo documento](/documenttype_documenttype)
- ![](./images/edit_record.png) Modifica di un [tipo documento](/documenttype_documenttype)
- ![](./images/delete_record.png) Cancellazione di un tipo documento
- ![](./images/view_record.png) Visualizzazione di un [tipo documento](/documenttype_documenttype)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
