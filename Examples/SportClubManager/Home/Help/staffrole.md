# Tipi Ruoli/Mansioni

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire i tipi ruoli e/o mansioni nella società sportiva.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista dei tipi ruoli e/o mansioni nella società sportiva.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione, sigla per le stampe)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [tipo ruolo/mansione](/staffrole_staffrole)
- ![](./images/edit_record.png) Modifica di un [tipo ruolo/mansione](/staffrole_staffrole)
- ![](./images/delete_record.png) Cancellazione di un tipo ruolo/mansione
- ![](./images/view_record.png) Visualizzazione di un [tipo ruolo/mansione](/staffrole_staffrole)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
