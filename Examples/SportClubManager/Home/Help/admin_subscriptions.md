# Iscrizioni

Nel [menu amministratore](/administrator_menu), alla voce Gestione Iscrizioni è possibile gestire le Iscrizioni.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle iscrizioni.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Nominativo: (Filtro su Nome e Cognome, Nome e Cognome genitore)

- Stagioni: (Filtro sulla stagione in base allo stato)
- Attuale
- Precedenti

- Corsi Attivi: (Filtro sulle quote iscrizione attive)

- Scadenza Visite: (Filtro su data scadenza visita medica)

- Stato Visite: (Filtro sullo stato delle visite mediche)
- Attive
- Prenotate
- Scadute
- Non Presente

- Stato Iscrizioni: (Filtro sullo status dell'iscrizione)
- Inserite
- Approvate
- Annullate
- Rifiutate

- Dalla data: (Filtro sulla data iscrizione)

- Alla data: (Filtro sulla data iscrizione)

- Anno nascita dal: (Filtro su data di nascita)

- Anno nascita al: (Filtro su data di nascita)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuova [Iscrizione](/admin_subscriptions_subscription)
- ![](./images/edit_record.png) Modifica di una [Iscrizione](/admin_subscriptions_subscription)
- ![](./images/delete_record.png) Cancellazione di una Iscrizione
- ![](./images/view_record.png) Visualizzazione di una [Iscrizione](/admin_subscriptions_subscription)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco delle iscrizioni
- ![](./images/approvaiscrizione.jpg) [Approvazione dell'iscrizione](/approve_subscription) sulle iscrizioni in status "inserito"
- ![](./images/rifiutaiscrizione.jpg) [Rifiuto dell'iscrizione](/reject_subscription) sulle iscrizioni in status "inserito"
