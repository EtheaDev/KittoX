# Campagne iscrizioni

Nel [menu amministratore](/administrator_menu), alla voce Gestione Iscrizioni è possibile gestire le Campagne iscrizioni.

Ogni anno occorre definire la Campagna iscrizioni, per permettere agli utenti (genitori) di iscrivere i propri figli ai vari corsi.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle campagne inserite per ogni stagione.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Mostra campagne: (filtra l'elenco in base allo stato della campagna):
- Attive
- Future
- Storico

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento nuova [Campagna](/admin_subscriptioncampaigns_subscriptioncampaign)
- ![](./images/edit_record.png) Modifica di una [Campagna](/admin_subscriptioncampaigns_subscriptioncampaign)
- ![](./images/delete_record.png) Cancellazione di una Campagna
- ![](./images/view_record.png) Visualizzazione di una [Campagna](/admin_subscriptioncampaigns_subscriptioncampaign)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco Campagne
