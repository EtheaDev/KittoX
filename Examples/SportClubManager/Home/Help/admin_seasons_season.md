# Maschera di Inserimento/Modifica/Visualizzazione delle stagioni

Maschera di Inserimento/Modifica/Visualizzazione delle [stagioni](/admin_seasons) sportive.

![Mappa stagioni](./images/stagionimappa.jpg)

**In questa maschera è possibile definire:**
## Codice
Codice identificativo della stagione.

## Stagione
Denominazione libera della stagione.

## Data inizio
Data inizio della stagione.

## Data fine
Data fine della stagione.
