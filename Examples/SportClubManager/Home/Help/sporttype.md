# Tipologie di sport

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri di sisteama è possibile gestire le tipologie di sport.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle tipologie di sport.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [tipologia di sport](/sporttype_sporttype)
- ![](./images/edit_record.png) Modifica di una [tipologia di sport](/sporttype_sporttype)
- ![](./images/delete_record.png) Cancellazione di una tipologia di sport
- ![](./images/view_record.png) Visualizzazione di una [tipologia di sport](/sporttype_sporttype)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
