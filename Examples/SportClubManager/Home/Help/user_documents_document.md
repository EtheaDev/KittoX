# Maschera visualizzazione dati del documento

Dai [documenti](/user_persondocuments) è possibile visualizzare i dati del documento.


![Visualizza documento](./images/user_documentimappa.png)


**In questa maschera è possibile visualizzare:**

#### Nominativo
Nominativo collegato al documento.

#### Tipo documento
Tipo di documento.

#### Descrizione documento
Descrizione del documento.

#### Data Rilascio
Data rilascio del documento.

#### Data Scadenza
Data scadenza del documento.

#### Rilasciato da
Ente che ha rilasciato il documento.

#### Numero
Numero identificativo del documento.

#### Scansione
Documento in formato digitale.
