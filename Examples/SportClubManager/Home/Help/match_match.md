# Maschera di Inserimento/Modifica/Visualizzazione delle partite

Maschera di Inserimento/Modifica/Visualizzazione delle [partite](/match).

![Mappa modifica/Visualizzazione](./images/partitemappa.jpg)

**In questa maschera è possibile definire:**
## Numero gara
Numero gara della partita.

## Descrizione giornata
Descrizione della giornata di campionato.

## Data partita
Data della partita.

## Ora partita
Orario della partita.

## Casalinga
Indica se la partita è in casa.

## Squadra
[Squadra](/admin_teams) di casa.

## Punti
Punti squadra di casa.

## Set
Per i tipi di sport con set numero set vinti dalla squadra di casa.

## Avversario
[Squadra](/admin_teams) avversaria.

## Punti avversario
Punti squadra avversaria.

## Set avversario
Per i tipi di sport con set numero set vinti dalla squadra avversaria.

## Data ritrovo
Data del ritrovo pre-partita.

## Luogo ritrovo
Luogo del ritrovo pre-partita.

## Note
Note libere sulla partita.

## Campionato
Il [campionato](/championship) della partita.


## Impianto sportivo
L'[impianto sportivo](/sportsfacility) della partita.

## Stagione
La [stagione](/admin_seasons_season) della partita.
