# Tipi d'impianti

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire i tipi d'impianti.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista dei tipi d'impianti.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [tipo d'impianto](/facilitytype_facilitytype)
- ![](./images/edit_record.png) Modifica di un [tipo d'impianto](/facilitytype_facilitytype)
- ![](./images/delete_record.png) Cancellazione di un tipo d'impianto
- ![](./images/view_record.png) Visualizzazione di un [tipo d'impianto](/facilitytype_facilitytype)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
