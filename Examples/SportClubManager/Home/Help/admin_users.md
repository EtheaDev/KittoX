# Utenti

Nel [menu amministratore](/administrator_menu), alla voce Amministrazione è possibile gestire gli utenti di [Sport Club Manager](/start).

### Finestra elenco con filtro di ricerca


Dall'elenco è possibile vedere la lista deli soci della società sportiva.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su Id account, cognome, nome e email)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [utente](/admin_users_user) di [Sport Club Manager](/start)
- ![](./images/edit_record.png) Modifica di un [utente](/admin_users_user) di [Sport Club Manager](/start)
- ![](./images/delete_record.png) Cancellazione di un socio
- ![](./images/view_record.png) Visualizzazione di un [utente](/admin_users_user) di [Sport Club Manager](/start)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco degli utenti di [Sport Club Manager](/start)
