# Tipi Registri IVA

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri Contabili è possibile gestire i tipi registri iva.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista dei tipi registri iva.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice e descrizione)

- Tipo registro: (Ricerca sul tipo registro)
- Acquisto
- Vendite

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [tipo registro IVA](/admin_vatregistertypes_vatregistertype)
- ![](./images/edit_record.png) Modifica di un [tipo registro IVA](/admin_vatregistertypes_vatregistertype)
- ![](./images/delete_record.png) Cancellazione di un tipo registro IVA
- ![](./images/view_record.png) Visualizzazione di un [tipo registro IVA](/admin_vatregistertypes_vatregistertype)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) dei tipi registri iva
