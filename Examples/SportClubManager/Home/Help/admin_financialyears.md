# Esercizi contabili

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri Contabili è possibile gestire gli esercizi contabili.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista degli esercizi contabili.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su Esercizio)

- Stato: (Ricerca sullo stato)
- Aperto
- Chiuso

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di un [esercizio contabile](/admin_financialyears_financialyear)
- ![](./images/edit_record.png) Modifica di un [esercizio contabile](/admin_financialyears_financialyear)
- ![](./images/delete_record.png) Cancellazione di un esercizio contabile
- ![](./images/view_record.png) Visualizzazione di un [esercizio contabile](/admin_financialyears_financialyear)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) degli esercizi contabili
