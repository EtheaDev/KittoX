# Registro Iva

Nel [menu amministratore](/administrator_menu), alla voce Contabilità è possibile consultare i registri IVA.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere l'elenco dei dettagli IVA.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Tipo registro IVA: (filtra l'elenco in base al [tipo registro IVA](/admin_vatregistertypes))

- Esercizio: (filtra l'elenco in base al [esercizio contabile](/admin_financialyears))

- Periodo: (filtra l'elenco in base al periodo della data documento del movimento contabile )
- I Trimestre
- II Trimestre
- III Trimestre
- IV Trimestre

- Mese: (filtra l'elenco in base la mese della data documento del movimento contabile )

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) del dettaglio dei registri IVA
