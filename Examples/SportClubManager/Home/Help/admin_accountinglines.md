# Righe contabili

Nel [menu amministratore](/administrator_menu), alla voce Consultazione Contabilità è possibile consultare le righe contabili.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista righe contabili con il raggruppamento per movimento.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Esercizio: (filtra l'elenco in base al [esercizio contabile](/admin_financialyears))

- Nr. mov.: (filtra l'elenco in base al numero movimento contabile)

- Dalla data: (filtra l'elenco in base alla data registrazione)

- Alla data: (filtra l'elenco in base alla data registrazione)


Sulla toolbar è possibile effettuare le operazioni di:
- ![](./images/view_record.png) Visualizzazione di un [riga contabile](/admin_accountinglines_vaccountingline)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco delle righe contabili
