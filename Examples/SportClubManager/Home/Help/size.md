# Taglie

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire le taglie per le divise.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle taglie per le divise.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [taglia](/size_size)
- ![](./images/edit_record.png) Modifica di una [taglia](/size_size)
- ![](./images/delete_record.png) Cancellazione di una taglia
- ![](./images/view_record.png) Visualizzazione di una [taglia](/size_size)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
