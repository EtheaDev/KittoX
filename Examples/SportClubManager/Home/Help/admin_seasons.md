# Stagioni

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire le stagioni sportive.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle stagioni.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Mostra campagne: (filtra l'elenco in base allo stato della campagna):
- Attive
- Future
- Storico
- Tutte

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [stagione](/admin_seasons_season)
- ![](./images/edit_record.png) Modifica di una [stagione](/admin_seasons_season)
- ![](./images/delete_record.png) Cancellazione di una stagione
- ![](./images/view_record.png) Visualizzazione di un [stagione](/admin_seasons_season)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea

Inoltre sono disponibili le operazioni speciali di:
- ![](./images/excel_document.png) [Esportazione in excel](/excel_export) elenco Quote
- ![](./images/duplicacampagne.png) [Duplica le campagne](/duplicate_campaigns)
