# Registrazione contabili automatiche Sport Club Manager

In [SportClubManager](/start) ci sono alcune funzioni gestionali che generano in automatico le relative scritture contabili.

Occorre configurare in modo corretto i parametri delle “[causali automatiche](/admin_automaticreasons)” per andare a definire che tipo di scritture automatiche il sistema deve effettuate all’accadimento di alcune operazioni.

N.B. Se la parametrizzazione non è configurata, il sistema non produce alcuna scrittura contabile automatica.

Le causali automatiche sono:
- [Approvazione iscrizione](/subscription_approval)
- [Pagamento iscrizione](/subscription_payment)
- [Apertura bilancio](/balance_sheet_opening)
- [Chiusura bilancio](/balance_sheet_closing)
- [Utile d’esercizio](/profit_for_the_year)
- [Utile d’esercizio precedente](/profit_for_previous_year)
- [Perdita d’esercizio](/loss_for_the_year)
- [Perdita d’esercizio precedente](/loss_for_previous_year)
