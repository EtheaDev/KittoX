# Nazione

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri geografici è possibile gestire le Nazioni.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle Nazioni.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su descrizione, Codice ISO, Codice ISO2, Codice ISTAT, Codice AT, Continente, Codice Area)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [nazione](/country_country)
- ![](./images/edit_record.png) Modifica di una [nazione](/country_country)
- ![](./images/delete_record.png) Cancellazione di una nazione
- ![](./images/view_record.png) Visualizzazione di una [nazione](/country_country)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
