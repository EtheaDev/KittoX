# Banche

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri amministrativi è possibile gestire le banche.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle banche.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, banca, iban, indirizzo, comune, cap, provincia, email, telefono)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [banca](/bank_bank)
- ![](./images/edit_record.png) Modifica di una [banca](/bank_bank)
- ![](./images/delete_record.png) Cancellazione di una banca
- ![](./images/view_record.png) Visualizzazione di una [banca](/bank_bank)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
