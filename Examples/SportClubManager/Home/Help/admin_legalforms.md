# Forme giuridiche

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri Contabili è possibile gestire le Forme giuridiche.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle Forme giuridiche.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, descrizione)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [forma giuridica](/admin_legalforms_legalform) della società sportiva
- ![](./images/edit_record.png) Modifica di una [forma giuridica](/admin_legalforms_legalform) della società sportiva
- ![](./images/delete_record.png) Cancellazione di un forma giuridica
- ![](./images/view_record.png) Visualizzazione di una [forma giuridica](/admin_legalforms_legalform) della società sportiva
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
