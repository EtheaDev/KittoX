# Categorie

Nel [menu amministratore](/administrator_menu), alla voce Parametri - Parametri gestionali è possibile gestire le categorie.

### Finestra elenco con filtro di ricerca

Dall'elenco è possibile vedere la lista delle categorie.

Sul pannello di ricerca è possibile indicare i "filtri" di ricerca:

- Ricerca libera: (Ricerca su codice, categoria)

Sulla toolbar è possibile effettuare le operazioni di:

- ![](./images/new_record.png) Inserimento di una [categoria](/category_category)
- ![](./images/edit_record.png) Modifica di una [categoria](/category_category)
- ![](./images/delete_record.png) Cancellazione di una categoria
- ![](./images/view_record.png) Visualizzazione di un [categoria](/category_category)
- ![](./images/refresh.png) Aggiornamento elenco (refresh)
- ![](./images/help.png) Guida in linea
