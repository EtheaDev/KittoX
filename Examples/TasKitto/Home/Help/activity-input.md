# Activity input

The list of activities, and the form to record one without passing through the wizard.

## What an activity is made of

| Field | |
|---|---|
| **Description** | What was done. Required. |
| **Phase** | The phase of the project. Required: it carries the project, and the project carries the customer. |
| **Employee** | Who did it. Required. |
| **Role** | In which role. Required. |
| **Type** | What kind of work. Required. |
| **Activity Date** | The day. Required. |
| **Start Time**, **End Time** | The hours of the day it took. |
| **Status** | Where it stands. |
| **Duration** | The hours, worked out from the times. |

## Finding what you recorded

The **Search panel** above the list is how you come back to an activity: by date, by employee, by
customer, by what the description says. The toolbar offers **Download in TXT** and **Download in
CSV** for what the list is showing.

## The same activities, elsewhere

The same rows are [grouped by type](activities-by-type), laid out as a
