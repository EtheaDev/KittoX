# Activities by type

The same activities as the [input list](activity-input), **grouped by their type**: analysis,
development, meeting, whatever the activity types table holds.

It answers the question the flat list answers badly - *where is the time going?* - without
counting anything: the rows are simply gathered under the type they belong to, and the groups can
be opened and closed.

For the same question answered with numbers instead of rows, see the [dashboard](dashboard) and
its pie chart by type.
