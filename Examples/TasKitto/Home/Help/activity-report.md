# Activity report

The same activities laid out as a **printable document** instead of a grid: a page built from a
template, which is what you hand to somebody who does not use the application.

The **Search panel** chooses what goes in it - a period, a customer, an employee - exactly as on
the [input list](activity-input). What the report shows is what the filters left.

**Download in TXT** takes it away as it stands.
