# Hair types

A short list of the hair colours the application knows: Blond, Walnut, Black, Silver, Red,
Platinum, and whatever else you add to it.

It is a **lookup table**: nobody types a colour by hand on a girl or a doll, they choose it from
here. That is what keeps the buttons of the **Hair Color** filter on the [girl list](girls)
meaningful - they filter on values that exist.

## What a hair type is made of

| Field | |
|---|---|
| **Hair Color** | The name of the colour. Required. |

## Before deleting one

A colour that a girl or a doll is using cannot be deleted. Change those first, or the application
will tell you how many are holding it.
